# 🚛 نظام إدارة أسطول الشاحنات والزيوت
### صندوق النظافة والتحسين - محافظة المهرة

تطبيق ويب سحابي يعمل على اللابتوب والجوال، مبني بـ Python + Streamlit،
ويحفظ بياناته تلقائياً في Google Sheets (مع تخزين محلي احتياطي).

---

## 🆕 التحديثات الأخيرة

- **إصلاح انهيار بدء التشغيل**: قراءات Google Sheets الأولى (الإعدادات،
  السجلات، دورات الزيت) محمية الآن بـ `_safe_load()` — أي عطل عابر عند
  الإقلاع (شبكة بطيئة، تهيئة باردة) يعرض تنبيهاً هادئاً بدل شاشة حمراء.
- **منع السحب العشوائي على الجوال (Pull-to-Refresh)**: `overscroll-behavior-y: contain`
  و`touch-action: pan-x pan-y` لتجربة أقرب لتطبيق أصلي عند التغليف كـ APK.
- **إصلاح جذري لتلميحات الأزرار**: أُزيل الاعتماد على `help=` في أزرار
  التنقل (كان يتموضع خطأً داخل الشريط العائم ويحجب الأزرار)، واستُبدل
  بتسمية دائمة ظاهرة تحت كل أيقونة؛ مع حماية CSS عامة إضافية
  (`pointer-events:none`) لأي طبقة تلميح أخرى في التطبيق.
- **إصلاح مفتاح تبديل الثيم**: القائمة الأصلية لستريملت (⋮ ← Settings)
  كانت مخفية بالخطأ ضمن إخفاء زر Deploy، ما عطّل تبديل الوضع الليلي/النهاري
  بالكامل. أُعيد إظهارها مع إبقاء زر Deploy الأسود وحده مخفياً.
- **شريط تنقل عائم زجاجي موحّد بأسلوب iOS يستبدل الشريط الجانبي بالكامل**:
  عمود رأسي عائم على حافة الشاشة في اللابتوب، وكبسولة أفقية عائمة أسفل
  الشاشة في الجوال — بنفس المكوّن البرمجي. ألوان زجاجية مشتقة من متغيرات
  ثيم ستريملت نفسها (فتبدو صحيحة في الوضعين معاً، بخلاف لون ثابت)، مع
  هامش آمن (`safe-area-inset-bottom`) أسفل الجوال، ومؤشر دائري شفاف
  ينزلق بسلاسة (`transition: transform`) خلف القسم النشط عند التنقل.
- **أيقونات خطية مفرغة متكيّفة مع الثيم**: أيقونات Material Symbols
  المدمجة في ستريملت (`currentColor`) فتنقلب تلقائياً بين الأبيض في
  الوضع الليلي والداكن في الوضع النهاري دون أي كود تلوين يدوي.
- **بطاقات مؤشرات متجاوبة حقاً**: أُصلح تعارض كان يقلب الترتيب (شاشات
  متوسطة تُجبر على عمود واحد، والأصغر منها على عمودين)، واستُبدل بشبكة
  CSS Grid مستقلة (`.stat-grid`): 5 أعمدة في اللابتوب، عمودان في الجوال.
- **حذف صفوف مباشرة من الجدول + تراجع فوري**: جدول "السجل العام" تفاعلي
  (`st.data_editor`) يتيح حذف أي صف مباشرة من علامة 🗑️، مع زر "تراجع عن
  آخر حذف" يستعيد السجل وعداد الزيت المرتبط به — ويعمل حتى لو حُذفت كل
  السجلات دفعة واحدة. مع تخصيص الأعمدة الظاهرة في الجدول حسب الحاجة.
- **مزامنة فورية**: أي حذف أو تعديل يُطبَّق على مصدر بيانات واحد مشترك
  (Google Sheets/CSV) فينعكس في كل صفحات التطبيق فور إعادة التشغيل.
- **ترتيب رقم السيارة عددياً**: `fleet/util.py` يحوّل العمود إلى نوع
  عددي صحيح ويفرز الجداول تصاعدياً ترتيباً طبيعياً (1، 2، 13، 14) بدل
  الأبجدي (1، 13، 14، 2).
- **إصلاح عرض البيانات**: `styles.safe_table()` تفرض أنواع بيانات ثابتة
  لكل عمود فلا تظهر نقاط أو رموز بدل القيم الحقيقية.
- **سجل تغيير الزيت** يسجّل التاريخ والوقت معاً، مع تنبيه منفصل عند 90%
  ("اقترب موعد تغيير الزيت") مستقل عن تنبيه 100%.
- **قسم تحليلات** (📈) برسوم بيانية لعدد العمليات، السيارات الأكثر
  استخدامًا، ومقارنة عدة سيارات — مع اختيار الفترة (يومي/شهري/سنوي).
- **منع تكرار حفظ الرسائل**: حماية داخل منطق الحفظ نفسه (بصمة محتوى
  الدفعة + قفل تنفيذ + نافذة زمنية) مع تفريغ حقل النص تلقائيًا بعد النجاح.
- **حفظ التقدم**: القسم المفتوح يُحفظ في رابط الصفحة، فيعود التطبيق لنفس
  القسم عند تحديث الصفحة أو إعادة فتحها بنفس الرابط.

## ▶️ خطوات التشغيل على اللابتوب

```bash
cd clean_fleet_app
pip install -r requirements.txt
streamlit run app.py
```

سيفتح التطبيق على `http://localhost:8501`.

للتشغيل من الجوال على نفس شبكة الواي فاي:

```bash
streamlit run app.py --server.address 0.0.0.0
```

ثم افتح من الجوال العنوان `http://<IP-اللابتوب>:8501`.

## ☁️ خطوات ربط Google Sheets (مرة واحدة فقط)

1. ادخل [console.cloud.google.com](https://console.cloud.google.com) وأنشئ مشروعاً جديداً.
2. من **APIs & Services ← Library** فعّل: **Google Sheets API** و **Google Drive API**.
3. من **APIs & Services ← Credentials ← Create Credentials ← Service Account**
   أنشئ حساب خدمة، ثم من تبويب **Keys ← Add Key ← JSON** نزّل ملف المفتاح.
4. انسخ `.streamlit/secrets.toml.example` باسم `.streamlit/secrets.toml`
   وضع فيه محتويات ملف JSON، وضع بريدك في `share_with`.
5. شغّل التطبيق — **سينشئ جدول البيانات وكل أوراقه تلقائياً**
   (السجلات، دورات_الزيت، سجل_تغيير_الزيت، الاعدادات) ويشاركه مع بريدك.
   لا تحتاج إنشاء أي جدول يدوياً.

> إذا لم تضع بيانات الاعتماد، يعمل التطبيق فوراً بالتخزين المحلي داخل مجلد `data/`.

## 🌐 النشر على Streamlit Cloud

1. ارفع المجلد إلى مستودع GitHub باسم `clean_fleet_app`
   (لا ترفع `secrets.toml` — مستثنى في `.gitignore`).
2. ادخل [share.streamlit.io](https://share.streamlit.io) ← **New app** ← اختر المستودع،
   واجعل Main file = `app.py`.
3. من **Settings ← Secrets** الصق محتوى `secrets.toml` كما هو.
4. اضغط Deploy — الرابط يعمل على اللابتوب والجوال مباشرة.

## 🛢️ طريقة حساب الزيت (كما هي مطلوبة)

- العداد يبدأ من **صفر** لكل سيارة.
- يتجمّع مع كل مسافة مسجّلة حتى يبلغ الحد الذي **تحدده أنت** (2500 كم افتراضياً).
- عند بلوغ الحد يظهر **تنبيه أحمر واضح** في لوحة التحكم وعند الإدخال.
- العداد **يتوقف عند الحد ولا يتجاوزه إطلاقاً** (لن يُكتب 2560).
- بعد الضغط على **«✅ تم تغيير الزيت»** تُغلق الدورة وتُسجَّل في سجل الزيت،
  وتبدأ **دورة جديدة من الصفر مستقلة تماماً** بلا ترحيل أي فائض.
- الحد والمعامل يُضبطان من **⚙️ الإعدادات العامة**.
